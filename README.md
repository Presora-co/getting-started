# Getting started with Presora

Tips, step-by-step guides and ready-made automation recipes for small businesses running their website, chatbot, bookings, customers and email on **[Presora](https://presora.co)**.

[Presora](https://presora.co) is an AI platform that builds and runs a small business's online presence in one place: an [AI website builder](https://presora.co/features/ai-website-builder) with [managed hosting](https://presora.co/features/website-hosting), an [AI chatbot](https://presora.co/features/ai-chatbot), contact and quote forms, [online booking](https://presora.co/features/online-booking), a [simple CRM](https://presora.co/features/crm), [business email](https://presora.co/features/business-email) and [workflow automations](https://presora.co/features/automations). It's made for local service businesses: trades, salons, clinics, gyms, restaurants, studios and professional services.

This repository is the practical companion to the [official Presora docs](https://presora.co/docs). The docs explain each screen. This repo puts those screens in order, adds tips from real setups, and collects automations you can switch on in a few minutes.

> **New to Presora?** Presora is invite-only for now. [Request an invite](https://presora.co/#waitlist) or [book an intro call](https://presora.co/booking). See [plans and pricing](https://presora.co/plans) for what each plan includes.

## Start here: your first hour

1. **Fill in Business info.** Name, services, contact details, address, opening hours, logo and photos. Everything else is built from it. → [Guide](guides/01-first-hour.md#1-fill-in-business-info)
2. **Build it into your website.** One button on *Finish setup* turns those details into real sections. → [Guide](guides/01-first-hour.md#2-build-it-into-your-website)
3. **Polish the site with AI.** Describe changes in plain English, or click any text to edit it. → [Guide](guides/02-website.md)
4. **Teach the chatbot.** Tell it your prices, delivery areas and policies so it can answer visitors. → [Guide](guides/04-chatbot-and-leads.md)
5. **Connect your domain.** Add three DNS records, and HTTPS is issued for you. → [Guide](guides/03-domain-and-email.md)
6. **Switch on a few automations.** Booking reminders and lead follow-ups are a good first pick. → [Recipes](automations/README.md)
